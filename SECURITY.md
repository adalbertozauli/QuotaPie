# Segurança

Não publique credenciais, cookies, arquivos de autenticação, histórico de uso real nem dumps completos do terminal em issues ou pull requests.

Se o repositório disponibilizar **Security → Report a vulnerability**, use esse canal privado. Caso a opção ainda não esteja habilitada, abra apenas uma solicitação genérica de contato privado, sem detalhes exploráveis ou dados sensíveis. Nenhum endereço de contato privado foi configurado nesta preparação.

O monitor depende de CLIs externos autenticados pelo usuário. A fonte Claude `/usage` é experimental e seu formato pode mudar. Não há garantia de atualização automática; consulte as releases e suas limitações.

Os pacotes locais atuais não são assinados com Developer ID nem notarizados. Isso deve ser informado nas releases. Checksums permitem comparar arquivos, mas não substituem uma assinatura de distribuidor confiável.
